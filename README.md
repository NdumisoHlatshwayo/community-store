# Community Store

Responsive HTML/CSS/JavaScript academic prototype.

## Demo
Email: demo@community.store  
Password: demo123

## Features
Registration/login, user roles, marketplace, product listings, search/filter/sort, product details, cart, calculated totals, demo checkout, Community Bulletin, profile and responsive layouts.

## Limitations
This front-end prototype uses browser localStorage. Authentication is not production security and payment is simulated; no real money is processed.
