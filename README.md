# Community Store — Final HTML/CSS/JavaScript Prototype

This version follows the supplied Community Store mock-up direction and the Term 2 feature backlog.

## Open the website
Extract the ZIP and double-click `index.html`.

No Python, Flask, Bash, npm or database server is required.

## Implemented prototype flows
- Registration and login with user roles
- Marketplace product feed
- Search, category filtering and sorting
- Product detail screen
- Cart with quantity changes and calculated totals
- Demo/sandbox-style checkout
- Seller listing creation
- Ratings displayed on products
- Notifications
- Community Bulletin and post creation
- User profile
- Saved/favourite products
- Responsive desktop and mobile layouts
- Browser persistence through localStorage

## Manual verification checklist
Use this checklist when producing the Term 3 evidence. Record the actual result and screenshot rather than assuming it passes.

1. Register a new account.
2. Sign out and sign back in.
3. Create a product listing.
4. Search for that product.
5. Filter products by category.
6. Open product details.
7. Save/favourite a product.
8. Add a product to the cart.
9. Increase/decrease cart quantity and verify totals.
10. Complete the demo checkout and confirm the success message.
11. Create a Community Bulletin post.
12. Open Notifications and mark all as read.
13. Test the layout at desktop and narrow/mobile widths.

## Important limitations
This is a functional front-end academic prototype. `localStorage` is not a production database or secure authentication system. The checkout simulates PayFast/SnapScan-style payment selection and does not process real money. Real email notifications, server authentication, vendor verification, fraud detection, HTTPS configuration and production payment processing require a backend and external services.

Do not describe an untested feature as passed in the final report. Test the artefact and use the real observed results.
